# Mn-SOD Comparative Genomics Project

## Overview
Comparative analysis of Manganese Superoxide Dismutase (Mn-SOD) across five bacterial species using bioinformatics tools on Linux.

## Species
- *Escherichia coli* (reference)
- *Pseudomonas aeruginosa*
- *Bacillus subtilis*
- *Staphylococcus aureus*
- *Salmonella enterica*

## Tools Used
- NCBI Protein Database
- Clustal Omega (Multiple Sequence Alignment)
- FastTree (Phylogenetic Tree Construction)
- Linux (Ubuntu WSL)

## Results
- *E. coli* and *Salmonella* are nearly identical (99.9% similarity)
- *Pseudomonas aeruginosa* is the most evolutionarily distant
- Conserved motif: `YAYDALEPHID` (manganese-binding site)

## Files
- `aligned_MnSOD.fasta` - Multiple sequence alignment
- `tree.nwk` - Phylogenetic tree in Newick format
- `Report.txt` - Full analysis report
